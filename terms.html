The product

EnvGate 0.2.0 is a small, zero-dependency Node.js 18+ CLI that checks environment files against .env.example, .env.sample, or .env.template, and can also scan workspaces, Docker Compose, and GitHub Actions env sources. Buyers receive a packaged release (source + CLI bundle) under the MIT License, including examples, tests, and a sample GitHub Actions workflow.

What is not included

  • --schema / typed JSON schema validation (not implemented; CLI exits with a clear “not supported” message if passed)
  • Multiline values, $VAR / ${VAR} expansion, escape sequences in quotes
  • Whole-repo or git-history scanning
  • License-key / DRM gating inside the binary
  • Guaranteed catch-all for every secret format
  • Promised support SLAs or release dates

Does not scan git history or arbitrary source files. Scan mode discovers env example files, Compose files, and GitHub Actions workflows; pair mode compares the paths you pass. Compose and Actions reading is not a full YAML parser. Secret detection is high-confidence and narrow, not exhaustive. This is a check helper, not a warranty of security or compliance.
